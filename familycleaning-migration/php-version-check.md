# 作業1：旧WordPressの PHP の版の確かめ方（PHP2Shell 対策）

## 結果（2026-10-23）

- **外からはまだ分かっていません。** Claude Code のクラウド環境はネットワーク制限で familycleaning.jp に接続できず（403）、応答ヘッダーを見られませんでした。
- 修正版（依頼文より）：**8.5.12 ／ 8.4.27 ／ 8.3.36 ／ 8.2.35** 以上。
  - この版番号と PHP2Shell の中身は、Claude が公式ページで確かめられていません（ネット制限のため）。サーバー会社のお知らせでも確認してください。
  - 8.1 以前は PHP 側のサポートが終わっているので、修正版は出ません。8.1 以前なら版を上げる必要があります。

## 店主の手順（どれか1つで分かります。上から簡単な順）

### A. パソコンで1行（ログイン不要・1分）

Windows の PowerShell を開いて、次をそのまま貼り付けて Enter：

```
curl.exe -sI https://familycleaning.jp/ | findstr /i "x-powered-by server"
```

- `x-powered-by: PHP/8.3.xx` のように出れば、それが版です。
- 何も出ない・`server: nginx` だけ → 隠されています。B か C で確かめてください。
- 自宅PCの Claude Code なら、`familycleaning-migration/tools/inventory.mjs` を動かすと、同じことを自動で調べて `summary.md` に書きます。

### B. WordPress の管理画面（3分）

1. 管理画面にログイン（パスワードは店主が入力）
2. 左メニュー「ツール」→「サイトヘルス」→ 上の「情報」タブ
3. 「サーバー」を開く →「PHP バージョン」の行を見る

### C. サーバー会社の管理画面（5分）

1. サーバー会社の管理画面にログイン
2. 「PHP Ver. 切替」「PHP 設定」などの名前のメニューを開く
3. familycleaning.jp の行に出ている版を見る
4. **修正版より古いとき**：同じ画面で新しい版に切り替えられます。ただし、切り替えるとプラグインが動かなくなることがあります。切り替えは店主の OK をもらってから、事前に WordPress のバックアップを取って行います（Claude が手順を作ります）

## 分かったら

版を Claude に伝えてください。`ISSUES.md` の I-01 を更新します。
