# 請求書デザイン（会計アプリ「請求書発行」用）

- `index.html`：A4縦の請求書。上段に「前月ご入金額・繰越金額・今月ご請求額」を表示する
- `sample.pdf`：見本データで印刷したもの

## 計算

- 繰越金額 ＝ 前月ご請求額 − 前月ご入金額
- 今月ご利用額（税込）＝ 明細の税抜合計 ＋ 消費税（10%・円未満切り捨て）
- 今月ご請求額 ＝ 繰越金額 ＋ 今月ご利用額（税込）

## 会計アプリへの組み込み

`index.html` の `INVOICE`（データ）だけを会計アプリの値に差し替える。
デザイン部分（`<style>` と描画の処理）はそのまま使う。

| 項目 | 会計アプリで入れる値 |
| --- | --- |
| `previousBilled` | 前月の請求書の「今月ご請求額」 |
| `previousPaid` | 前月分の入金額 |
| `items` | アステンポ CSV から抽出した明細（`price` は単価。`taxIncluded` で税込／税抜を指定） |
| `to` / `number` / `issueDate` / `closingLabel` / `dueDate` | 宛先・番号・日付 |

明細が多いときは自動で2枚目に続く（見出し行は2枚目にも出る）。

## アステンポのCSVを読み込む（ブラウザだけで使う）

`index.html` をブラウザで開き、上の「CSVを読み込む」でアステンポの「預り履歴」CSVを選ぶ。
読み込みはブラウザの中だけで行い、お客様のデータは外部に送らない（CSVはリポジトリに入れない）。

1. 請求する月を選ぶ（初期値は先月）。その月の売上日の明細だけが並ぶ
2. 金額の扱いを選ぶ（税込なら合計はそのまま・消費税は「うち」で表示。税抜なら10%を足す）
3. 宛名を確認する（CSVの顧客名が入る。半角カナは全角にそろえる）
4. 前月ご請求額・前月ご入金額を入力する（CSVに入っていないため）
5. 「印刷・PDF保存」で印刷する（操作パネルは印刷されない）

CSVの形式（2026年10月に確認）

- 文字コードは Shift_JIS。先頭に「預り履歴」「顧客コード：[ … ]  顧客名：[ … ]」の行があり、その下に見出し行
- 見出し：店舗, 売上日, タグ, 商品, 付加価値, 金額, 外注, 返却日, 仕上日, 商品メモ, 画像, サイン
- 1点（タグ）1行。金額は付加価値（シルクなど）を含んだ額。料金のある付加価値は品目名に（ ）で添える
- 発行日はその月の末日、お支払期限は翌月末日、請求書番号は「年月-顧客コード下4桁」
