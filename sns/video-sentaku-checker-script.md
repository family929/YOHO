# 洗濯表示チェッカー 紹介動画　構成案と台本

> ※読み上げ台本は短縮版（約1分）に変更しました。話す内容は `video-narration.md` が最新です。下の3分版の構成は、画面の見せ方の参考として使ってください。

## 基本の形
- **長さ**：約3分（YouTube 横長 16:9）。あとで縦長ショート（約45秒）も切り出せる構成
- **画面**：後ろにチェッカーの操作画面、右下の丸の中に話す人の顔（ワイプ）、下に字幕
- **話す人**：お店の人（台本では【お名前】としています。ふだんの呼ばれ方に置き換えてください）
- **対象**：洗濯表示を覚えるのが大変で、記号を見て理解して覚える時間がもったいないと感じている人
- **伝えたい一言**：「洗濯表示は、覚えなくていい。タグと同じ記号を選ぶだけ」
- **ねらい**：「どんな人に」「なぜ」作ったかを伝えて、使ってみたいと思ってもらう。最後に宅配・LINE相談もさりげなく案内

## 画面レイアウト（横長）
```
┌──────────────────────────────────────┐
│ ▬▬▬▬▬▬▬▬▬▬ 紺の細い帯 ▬▬▬▬▬▬▬▬▬▬▬▬▬▬ │
│                                      │
│  [見出しテロップ]   ┌────────┐         │
│  例：なぜ作った？   │ スマホ │         │
│                     │ の画面 │         │
│  生成り色の背景     │（録画）│   ◯ 顔 │
│                     └────────┘         │
│ ───── 字幕（話している言葉）───────── │
└──────────────────────────────────────┘
```
- スマホの画面録画は縦長なので、中央に置き、左右の空きに見出しテロップを出す
- 顔の丸は右下。チェッカーの判定やボタンに重ならない位置に
- 色はチェッカーに合わせる：背景 生成り（#f5f0e6）、文字 紺（#1f3a5f）、強調 朱（#c8553d）

## 準備するもの
- チェッカーの画面録画（スマホの画面収録でOK）。下の「操作」欄の順に操作したものを1本
- 実物の衣類1枚（手洗いのニットなど）。冒頭とデモでタグを見せる
- 顔と声の収録（画面録画とは別撮りでも、同時でも）

## デモで使う記号（実際にこの順で選ぶと「家で洗えます（注意あり）」になります）
| 問 | 選ぶ記号 |
|---|---|
| 1 洗濯 | 手洗い 30℃ |
| 2 漂白 | 漂白禁止 |
| 3 乾燥機 | 乾燥機禁止 |
| 4 干し方 | 平干し 日陰 |
| 5 アイロン | 低温 120℃ |
| 6 ドライ | P |
| 7 ウエット | W |

手元の衣類のタグと違う場合は、実物のタグどおりに選んでください（判定も変わります）。

## 構成と台本

### ① つかみ（0:00〜0:15）
- **画面**：衣類のタグのアップ → チェッカーのタイトル画面「その洋服 洗える？」
- **見出しテロップ**：「洗濯表示、覚えてますか？」
- **台本**
  > 洋服のタグについている、この小さな記号。
  > 全部覚えていますか？ ……正直、覚えるの大変ですよね。

### ② 自己紹介（0:15〜0:25）
- **画面**：タイトル画面のまま（または1問目の画面）
- **見出しテロップ**：「北九州のクリーニング店です」
- **台本**
  > こんにちは。北九州のファミリークリーニングの【お名前】です。
  > 今日は、私たちが作った「洗濯表示チェッカー」をご紹介します。

### ③ どんな人のために、なぜ作ったか（0:25〜1:00）
- **画面**：1問目「洗濯おけの記号はどれですか？」の画面で止めておく
- **見出しテロップ**：「覚えなくていい」→「こんな人に」
- **台本**
  > 洗濯表示って、おけに数字、三角に斜線、四角に丸……。種類が40以上あるんです。
  > しかも2024年に一部が改正されて、新しい記号も増えました。
  > 一つひとつ見て、意味を調べて、覚えて……その時間、正直もったいないと思いませんか？
  >
  > お店でもよく聞かれるんです。「この服、家で洗っても大丈夫でしたか？」って。
  > 【ここに実際にあったエピソードを一言。例：縮ませてしまって持ってこられた方の話 など】
  >
  > だから、作りました。洗濯表示は、覚えなくていい。
  > タグと同じ記号をスマホで選ぶだけで、「家で洗えるか」「どう洗えばいいか」が分かる。
  > 覚える時間を使わずに、すぐ答えが知りたい方のためのチェッカーです。

### ④ 実際に使ってみる（1:00〜2:05）
- **画面**：デモの記号を1問ずつタップ → 結果画面 → 注意点をゆっくりスクロール
- **見出しテロップ**：「使い方」→「全7問、タップするだけ」→「判定は3つ」
- **台本**
  > 使い方はかんたんです。今日はこのニットで試してみます。
  > まず洗濯の記号。タグを見ると……手洗いの30℃ですね。これをタップ。
  > 選ぶと、自動で次の質問に進みます。
  > 漂白は「禁止」、乾燥機も「禁止」、干し方は「日陰の平干し」……
  > タグにない記号のときは「タグにない」を押せば大丈夫です。
  > 全部で7問。終わると、判定が出ます。
  >
  > このニットは「家で洗えます、ただし注意あり」。
  > 手洗いで押し洗い、乾燥機は使わない、日陰で平らに干す——と、気をつけることが一覧で出ます。
  > 判定は「家で洗える」「注意あり」「プロに任せる」の3つです。

### ⑤ 作るときに大事にしたこと（2:05〜2:40）
- **画面**：結果画面の下の「選んだ記号の意味」をスクロール → シェアボタン
- **見出しテロップ**：「迷ったら、プロに任せる」→「無料・登録なし」
- **台本**
  > 作るときに一つ決めたことがあります。
  > 家で洗えるか迷う組み合わせのときは、「プロに任せる」と判定するようにしました。
  > 大切な服を傷めてほしくないので、クリーニング店として、安全なほうをおすすめしたいと思ったからです。
  >
  > それから、無料で、登録もいりません。
  > 選んだ内容はどこにも送られないので、気軽に使ってください。

### ⑥ まとめ・ご案内（2:40〜3:00）
- **画面**：QRコード入りの画像（`sns/sentaku-checker-story.png` など）
- **見出しテロップ**：「概要欄のリンクから使えます」

  > ブックマークしておくと、すぐ開けて便利です。リンクは概要欄に貼っています。

## 縦長ショート版（約45秒）の切り出し方
- ①（0:00〜0:15）→ ④のタップ部分を早送り（約20秒）→ 結果画面 → ⑥の最後の2文
- 縦長なので、スマホ画面を全画面にし、顔の丸は右上か右下に小さく

## 字幕・テロップのコツ
- 字幕は話した言葉をそのまま。1行15文字くらいで区切る
- 見出しテロップは短く（10文字以内）。朱色は「大事な一言」だけに使う
- 判定が出た瞬間は、少し間を置いて画面を見せる

## 気をつけること
- 「必ず洗える」「失敗しない」など言い切る表現は使わない（判定は目安）
- エピソードは実際にあったことだけを話す。思い当たらなければ③の【 】の1文は省いてOK
- 洗剤の比較記事など、広告を含むリンクを動画内で紹介する場合は「広告を含みます」と一言添える
